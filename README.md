# Sidebar Notes

A lightweight notepad Firefox extension integrated into the native sidebar. Create, search, and favorite notes, organize them into folders with drag and drop, format text, paste or drop and resize images, switch themes, and export notes as HTML. Notes locally save automatically.

Available on the [Firefox Add-ons store](https://addons.mozilla.org/en-US/firefox/addon/sidebar-notes/).

## Keyboard Shortcuts

- macOS: Cmd + .
- Windows/Linux: Ctrl + .
